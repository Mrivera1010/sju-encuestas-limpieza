Encuestas de limpieza SJU

Seleccione una encuesta para verla tal como la verían pasajeros, socios comerciales y personal. Cada código QR o enlace lleva directo a una encuesta y registra el área automáticamente.

Así llegan los pasajeros a la encuesta

Letreros con un código QR único por ubicación (baños, puertas, food court, counters, reclamo de equipaje, curbside y estacionamiento). Al escanearlo, la encuesta registra el área automáticamente. Ejemplo ilustrativo: el texto y el código se ajustarán según la encuesta y el área.

Enlaces para códigos QR y correos

Cada enlace abre una sola encuesta. Para pasajeros, agregue la ubicación con loc= y ese texto se guarda con cada respuesta.
